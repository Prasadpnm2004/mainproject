# PACM — Plan-Action Consistency Monitoring

> **A lightweight, protocol-agnostic runtime defense against context-aware prompt injection in tool-using / MCP-connected LLM agents.**
>
> *Research project — Phase 1 in progress (Session 1: Environment setup & baseline)*

---

## Research Overview

PACM sits as middleware between an LLM agent's reasoning step and its tool-call execution. It measures divergence between the agent's *declared intent* and its *actual tool call*, augmented with MCP server/tool trust scores, to detect prompt-injection-induced behavioral hijacking without retraining or rewriting the execution engine.

See [`PACM_Research_Guide.md`](PACM_Research_Guide.md) for the full research proposal, threat model, and 12-week execution plan.

## Quickstart

### 1. Set up the environment

```bash
# Create and activate virtual environment
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS/Linux

# Install dependencies
pip install -r requirements.txt
```

### 2. Configure API keys

```bash
copy .env.template .env         # Windows
# cp .env.template .env         # macOS/Linux
# Edit .env and set OPENAI_API_KEY and/or ANTHROPIC_API_KEY
```

### 3. Run unit tests (no API keys needed)

```bash
pytest tests/ -v -m "not integration"
```

### 4. Run the baseline experiment

```bash
# Requires OPENAI_API_KEY in .env
python -m experiments.run_baseline --model gpt-4o-mini --max-iter 10

# Results written to experiments/baseline_results.jsonl
```

## Key Metrics (from PACM_Research_Guide §10)

| Metric | Symbol | Definition |
|---|---|---|
| Attack Block Rate | ABR | % of injection attempts blocked |
| Benign Task Success Rate | BTSR | % of legitimate tasks completed correctly |
| False Positive Rate | FPR | % of legitimate tool calls flagged |
| Latency Overhead | — | Added wall-clock time per tool call |
| Token/Cost Overhead | — | Extra LLM tokens vs. baseline |
